# Buni Atelier

> **Pan-African luxury art marketplace — Where Africa Creates**

A full-scale e-commerce marketplace connecting African artists, sculptors, photographers, and textile makers with global luxury buyers. Built as a complete full-stack product with artist portals, collector accounts, a commission engine, and a comprehensive admin operations centre.

🔗 **[View Live Site](https://buni-atelier-0ute.onrender.com)**

## Features

- **Public marketplace** — curated collections, category filtering, Africa-wide artist map, and artwork detail pages with high-res zoom and cultural provenance
- **Artist portal** — manage listings, track earnings, request payouts
- **Collector portal** — personal collection, wishlist, purchase history, and VIP tier progression (Curious → Collector → Patron → Grand Patron)
- **Admin operations centre** — manage artworks, artists, collectors, orders, payouts, revenue analytics, and WhatsApp logs
- **20% commission engine** — built into the order creation route with server-side payout calculation
- **WhatsApp automation** — real-time buyer and artist notifications via CallMeBot
- **Make an offer / Buy now** — full transactional flow with offer negotiation
